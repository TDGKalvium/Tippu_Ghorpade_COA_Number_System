RUN
1. Extract the ZIP.
2. Open index.html in a current browser (Chrome, Edge, or Firefox).
3. Select input base: Binary, Octal, Decimal, or Hexadecimal.
4. Enter a valid non-negative integer and click Convert number.
5. Try the quick examples and copy buttons.

FEATURES
- Responsive professional dashboard
- Conversion among base 2, 8, 10 and 16
- Exact large integer handling with JavaScript BigInt
- Input validation
- Place-value breakdown into decimal
- Recent conversion history
- Copy result buttons
- No install or internet connection required

Examples:
Binary 101101 -> Octal 55, Decimal 45, Hexadecimal 2D.
All files run locally; no external libraries or server required.
